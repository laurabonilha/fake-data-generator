Sobre o Projeto

🎯 Objetivo

O Fake Data Generator é uma ferramenta desenvolvida para auxiliar desenvolvedores e testadores a gerar dados realistas para ambientes de desenvolvimento e testes.

🚀 Funcionalidades

  • Geração de dados de pessoas (nome, CPF, email, telefone, endereço)
  • Geração de dados de empresas (CNPJ, razão social, contatos)
  • Exportação em múltiplos formatos (JSON, CSV)
  • Preview dos dados antes do download
  • Geração de até 1000 registros por vez

🛠️ Tecnologias

  • Django: Framework web Python
  • Faker: Biblioteca de geração de dados
  • Bootstrap: Framework CSS
  • Python: Linguagem de programação
  • SQLite: Banco de dados
  • JavaScript: Interatividade do frontend

📝 Versão

V0.1.0 - Versão inicial do projeto com funcionalidades básicas.
